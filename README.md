# ФинПинг (FinPing) Landing Page

Рекламный лендинг для Telegram-бота финансового пульса для микробизнеса в СНГ.

## О продукте

**ФинПинг** — это Telegram-бот, который помогает ИП и микробизнесу (1-5 человек) держать руку на пульсе своих финансов без использования сложных и дорогих систем учета.

### Ключевые возможности:
- **Ежедневная сводка:** Каждое утро (в 9:00) бот присылает данные о доходах, расходах и остатке за предыдущий день.
- **Прогноз кассового разрыва:** Бот заранее предупреждает о возможных проблемах с наличностью.
- **Автоматизация:** Прямая интеграция с Т-Банк и Модульбанк для автоматической загрузки транзакций.
- **Доступность:** Работает прямо в Telegram, не требует установки отдельных приложений.
- **Цена:** 500 ₽/мес (в 4 раза дешевле конкурентов) с бесплатным пробным периодом 7 дней.

## Технические детали

Лендинг реализован в виде одного статического HTML-файла (`index.html`), что обеспечивает максимальную скорость загрузки и простоту деплоя.

- **Стек:** HTML5, CSS3 (Inline), Vanilla JS.
- **Дизайн:** Mobile-first, минималистичный стиль, темная Hero-секция, светлые контентные блоки.
- **Шрифты:** Inter (Google Fonts).
- **Акцентный цвет:** #0088cc (Telegram Blue).

## Как запустить

Просто откройте файл `index.html` в любом современном браузере.

```bash
# Если у вас установлен python, можно запустить локальный сервер:
python3 -m http.server 8000
```
Затем перейдите по адресу `http://localhost:8000`.
